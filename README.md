# 泰拉瑞亚 · 酒狐npc仆从

Terraria **tModLoader 1.4.4** 的自定义仆从模组：一只跟着玩家跑、能战斗、能聊天、能喂食、能摸摸头的狐狸女仆「酒狐」。

---

## 直接安装（不用编译）

下载仓库根目录的 **`酒狐npc仆从.tmod`**，放进

```
Documents\My Games\Terraria\tModLoader\Mods\
```

然后进游戏 →「模组」页 → 刷新 → 启用 **酒狐npc仆从**。

> 需要 tModLoader 1.4.4（或兼容的 1.4.4.x）。`.tmod` 是构建产物，和当前源码同步。

## 从源码编译

需要 tModLoader 的模组开发环境（`tModLoader.targets`）。

```powershell
dotnet build "酒狐npc仆从.csproj" -v q --nologo
```

编译成功会把新的 `酒狐npc仆从.tmod` 写进上面的 Mods 目录。

## 新皮肤

客户端配置：**设置 → 模组配置 → 酒狐任务配置 → 使用新皮肤（蓝发女仆装）**，默认关闭。

- 三张核心贴图任一缺失/加载失败都会整体回退到原皮肤，不影响存档。
- 帧布局：`zhanli.png` 单帧 40×56，`paobu.png` 3 帧 40×120→(竖排 40×168 也支持)，`Armor_zhandou.png` 6 帧 240×56（横排）。
- 代码里的 `取帧区域()` 自动识别**竖排/横排**两种布局。
- `petpet_sheet.png` 摸头表固定 10 帧 × 72×56 = 720×56。

## 贴图量产

`报错/` 里是生成脚本，思路参考 [PixelOE](https://github.com/KohakuBlueleaf/PixelOE)（对比度感知的轮廓扩张 + 不做平均的降采样）：

1. 先把高对比细节（眼线、瞳孔）加粗，避免缩小后被吃掉
2. 按块取**主导色**缩到 40×56（不做跨边缘平均，所以不糊）
3. 脸部按 5 类（皮肤 / 眼白 / 眼线 / 虹膜 / 嘴）逐块归类，补回丢掉的细节像素

| 脚本 | 用途 |
|---|---|
| `pxoe.ps1` | 主管线：去背景 → 细节扩张 → 主导色降采样 → 调色板量化 → 描边 → 脸部重建 |
| `petsheet.py` / `petsheet.ps1` | 摸头动画（gif/webp）→ 720×56 摸头表 |
| `extract_frames.py` | 拆 gif / webp 动画帧 |
| `up.ps1` / `crop.ps1` | 放大预览、裁切检查（最近邻，不模糊） |

```powershell
.\报错\pxoe.ps1 -InFile 原图.jpg -OutFile zhanli.png
python .\报错\petsheet.py petpet.gif petpet_sheet.png 72 56 52
```
